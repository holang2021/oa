2026-11-09 · 框线对齐币种子表头 + 金额符号

PI 币种：与表格框线对齐，金额带所选符号

刘总原话：「框线对齐插入币种选择，在表格单价等处显示为选择的币种符号」

原来红框那个位置是表格外面一行孤零零的右对齐文字（US Dollar），既没有框线、也不像表格的一部分；表格里的单价、总价还是纯数字，客户看不出币种。现改成表格内带框线的币种子表头（跨金额 2 列，与表格框线完全对齐），并让所有金额自动带所选币种符号。

一句话：币种在 PI 表单的「币种」下拉里选（USD / EUR / CNY / GBP / JPY / HKD），选完点预览或打印，红框位置自动显示「符号 + 币种名称」（如 $ US Dollar），表格单价 / 总价 / TOTAL 同步显示 $13,800.00 这样的带符号金额。
