PI 打印预览：去掉被硬撑出来的大空白

刘总原话：「根据内容需要不需要留那么大的空白」

您红框圈的那块空白，不是业务上要预留的——是预览渲染里明细表容器被设成 flex-1（自动撑满纸张剩余高度），把 TOTAL、交易条款、Bank details 一起推到了页底。内容少时被撑得特别明显，看起来像留了大半页空白。现已改成内容有多少就占多高。

一句话：去掉表格的自动撑高与页脚的自动贴底，所有区块从上往下自然紧凑排列；明细多时仍会自然往下延伸、超一页正常分页，不会截断。

2 · 具体改了什么

改动为什么
预览表格容器去掉 flex-1根因。原来表格块会吃掉纸张所有剩余高度，TOTAL / 条款 / 银行块被推到页底。
页脚去掉 mt-auto / margin-top:autoCI / PL 模板的页脚同理会自动贴底，一并按「内容决定高度」处理，避免同类空白。
空明细不再印内部提示截图里那行「尚未录入商品明细，请在表单中填写」是给销售看的操作提示，不该出现在客户单据上。现在无明细时表格只给一行空单元格。
打印版式 / 字体字号不变上一步按真实单据重建的 logo、居中抬头、两栏、5 列表格、OA 字体字号 token 全部保留。
