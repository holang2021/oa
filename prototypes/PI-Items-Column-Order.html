2026-11-09 · 产品编号移位

「产品编号」挪到 DESCRIPTION 后面

刘总原话：「产品型号，移动到 DESCRIPTION OF PRODUCTS * 后面」

把商品明细表格里的「产品编号」列，从原来的第 2 列（HS Code 前面）移到 DESCRIPTION OF PRODUCTS * 后面。表单表格是 table-fixed + <colgroup> 固定列宽，所以表头、数据行、列宽三处必须一起挪，只改一处就会表头和输入框错列。

一句话：现在录入顺序是 No. → HS Code → 产品名称描述 → 产品编号 → Qty → 单位 → Unit Price → Total；销售先写清楚是什么产品，再补型号/料号，更顺手。
