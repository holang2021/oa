商品明细「单位」默认填 pcs，随时能改

刘总原话：「单位默认为pcs，保留修改的权力」

新建 PI 时第一行、点「新增一行」加的行、以及从报价单带进来的行，单位都自动填好 pcs，销售不用每次手打。但它只是个初始值：单位框仍是普通输入框，卖成套设备可改成 set、按重量可改 kg，也能填中文，系统不锁、不建枚举、不写死。

一句话：少填一次，但一样都没少权限。只有 PI 确认后才冻结不能改（这本来就是系统的冻结规则），草稿状态随时改。

2 · 三个入口都带默认值

怎么产生这一行单位初始值说明
新建 PI 的第一行pcs打开新建页就有
点「新增一行」pcs加几行都是 pcs
从报价单带入报价单单位优先报价单行项本来写了单位就用它；没写才兜底 pcs
打开已保存的旧 PI保持原样不偷偷改历史单据

3 · 「保留修改的权力」具体怎么保障

担心的事实际做法
会不会变成写死、改不了？仍是普通文本输入框，有 onChange，没有 readOnly，没有固定值
会不会变成只能选的下拉？不会。用「建议列表」给常用单位，仍可直接打字输入任意单位（中英文都行）
什么时候不能改？只有 PI 已确认后禁用（全表单统一冻结规则）；草稿状态随时改
改了能存下来吗？能。端到端实测：pcs 与 set 存后重开都原样读回
会不会为「单位」新建表 / 字段？不会。仍复用 items_json 一个字段，零迁移、零新接口
后续（刘总 11-09 已拍板）：打印件明细表列头已由 Qty (set) 改为中性的 Qty，PI / CI / PL 三张一起改，不再与行内 1 pcs 打架。详见对照页 PI-Qty-Header.html。
