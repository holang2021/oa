3 · 新增 / 删除 / 默认协同怎么用

新增点「新增账户」→ 选账户性质（外币 / 人民币）→ 填币种代码（可自由输入，不写死）与银行账号 → 添加。公共开户行等资料从同性质账户带入，账号必须自己填，避免误带旧账号。
编辑外币账户只显示 5 个英文字段 + PAYMENT ROUTE；人民币账户只显示 6 个中文字段 + 回款路径，不再混显。
删除编辑态里点「删除账户」，先二次确认；若删的是默认账户，同币种剩余的第一套自动顶上；某币种最后一套被删会提示该币种开单将显示「待维护」。
默认协同同币种多套时点「设为默认」，互斥；开 PI 时系统自动带出这一套。新增 / 删除 / 改默认都要点「保存全部」才正式生效。

3能否复用既有机制？能。账户仍走 /field-configs 的 bank_accounts 整存 JSON；打印仍是原 6 行 field；只给渲染器加一个动态标签能力。
4是否新增 Model / 表 / 接口？否。仅 JSON 内部加一个 id 字段与几个标签键；零迁移脚本。
5是不是按模板反推字段？否。语言口径来自刘总业务定义与真实单据（外贸单据英文、内销开票资料中文），没有新增业务字段。
6会影响最终交易事实吗？不改变账号与金额；打印件银行块随账户性质切换语言。已确认单据仍按 CONFIRMED 冻结规则。
7会让销售回 Excel / 微信重做吗？不会。按币种自动协同不变，销售照样不用挑账户。
8是不是「以后可能 / 为 AI / 更规范」？不是。三条都是刘总对着真实页面指出的当前缺陷。
9回滚与部署代价？纯前端 + 一份配置数据；老配置缺 id 会自动补齐不丢账号；「恢复内置开票资料」可一键回到三套盖章账户。
