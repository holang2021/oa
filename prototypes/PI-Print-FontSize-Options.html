先回答第二个问题：UI 基线没有定义打印件的字体字号。docs/OA_UI_Foundation_V0.1.md 第 5 节定的是屏幕字号（页面标题 24、模块标题 18、小标题 16、正文/表格/Label 14、辅助 13，并写明「正常业务信息不要低于 13px」）；全文唯一提到 A4 的只有接收说明里那句「报价单 A4 区真实 logo 铁律独立有效」（说的是 logo，不是字）。

打印件另有一套 src/services/printDesignTokens.ts：字体栈严格镜像 --font-sans ✅，但 7 档字号是 11-08 按"真实单据版式 + OA UI 阶梯折算"自己定的——正文 11、页头 10、标签 9、表格 10、小字 9。主体只有 9–11px，既低于 UI 基线的 13px 下限，也没有设计依据。您看着不爽是有道理的。

3 · 第一个问题（买方资料）已经改好了

  • 在哪填：PI 表单右侧「客户信息」卡片里，新增「买方抬头」区，含 Address / CONTACT / Tel. / E-mail 四个输入框。
  • 选客户会自动带出（地址拼 address+addressDetail，联系人取客户联系人或 contacts[0]，电话可用公司电话兜底）；带出后可自由改，改动只属于这张 PI，不回写客户资料。
  • 随 PI 的 notes 一起保存、重开原样回填；打印件左上方直接取这些值。零新表、零新列、零新接口。
  • 之前那几行空的根因：客户模型里 contactName/Phone/Email 来自 contacts[0]，客户没建联系人（或列表接口没带 contacts）就全空，而表单里又没有任何地方能补填。
