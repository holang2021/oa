PI 商品明细 · 销售现在可以直接填了

2026-11-08 · 刘总一线反馈：「产品销售单价、明细没有地方能填写」
原来 PI 只有一个总金额框，明细只能从「已接受的报价单」带出；报价单没在系统里做完时，销售就只能回 Excel 手工做单——这违反了「不让销售回 Word/Excel/微信重做」的硬约束。
现在 PI 表单里新增一张可增删的商品明细表：HS Code、品名、数量、单位、单价都能直接填，金额自动算，合计可一键带出 PI 金额，明细会随单据保存，导出 PDF 直接印到单据上。

真实流程 / 真实单据？ 有——您给的 Allum PI 就是 3 行明细，含 HS Code、数量、单价、金额。
刘总确认过？ 有——本条反馈即明确诉求。生产数据？ PI 表 0 行（未录，不是不存在业务）。
当前代码支持吗？ 不支持，原表只有总金额。会让销售回 Excel 吗？ 不加就会，加才符合硬约束。
是「以后可能 / 为 AI / 更规范」吗？ 不是，是一线当场要用。
最小结构？ 不为设备/配件/运杂/服务各建一张表，只给 PI 加 1 个 JSON 列存行项；不建 BOM、不新建 API（复用既有 PUT /pi/:id）。
