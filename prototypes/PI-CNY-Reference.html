2026-11-09 · 内部参考，不进客户单据

把总价折成人民币，放到总金额旁边

刘总原话：「有时候销售会好奇自己能拿多少奖金，那得看一下这个价格折算成人民币大概是多少钱。找一个合适的位置，把这个总价折算成人民币的金额显示出来」

先查了现状：折算逻辑其实早就有——convertToCNY() 走「系统设置 → 币种与汇率」的真汇率，金额也算出来了。问题是它只作为一行灰色小字，埋在「金额与贸易条款」卡片最底下、夹在收款账户和付款条款之间，销售基本看不到。所以这次不是加计算，是把这个数提到总金额旁边、做成一眼能看到的金额。

一句话：填完明细看到总额的那一条，现在并排显示「折合人民币 ¥2,461.92 · 内部参考」；客户拿到的 PI / PDF 里一个字都不会出现。

1 · 改前 / 改后（合计条）

改前
PI 总金额（按商品明细自动算出）：USD 368.00 改单价或数量，金额自动更新；保存与导出 PDF 都用这个数。
↓ 折到很下面、卡片底部才有这么一行小字，销售很难注意到：
内部参考（不输出到给客户的 PI / PDF）：按系统汇率约折合 ¥2,461.92；采用 1 USD = 6.6908 CNY……
  • 折算金额和总金额不在同一个地方，要往下翻才看得到
  • 灰色 13px 小字混在一大段汇率说明里，视觉上像"备注"不像"金额"
  • 销售想知道这单值多少人民币，得自己找、甚至自己拿计算器乘
改后
PI 总金额（按商品明细自动算出）：USD 368.00 折合人民币¥2,461.92· 内部参考 改单价或数量，金额自动更新；保存与导出 PDF 都用这个数。
卡片底部仍保留一行说明，但只讲汇率来源与更新时间，不再重复那个金额：
内部参考（不输出到给客户的 PI / PDF）：上方人民币折算采用 1 USD = 6.6908 CNY（更新于 …），可在「系统设置 → 币种与汇率」维护；折算金额不会出现在客户单据上。
  • 总额与人民币折算并排，同一眼就能看完
  • 白底卡片 + 主色 16px 数字，像"金额"而不是"备注"
  • 明确带「· 内部参考」，销售不会误以为这是要报给客户的数
  • 改数量/单价、切币种、汇率更新，两个数一起变

2 · 为什么选这个位置

候选位置判断
商品明细下方合计条 ✅采纳
「金额与贸易条款」再加第 4 列上一轮刚把 4 列收敛成 3 列修对齐，加回去会重犯
收款账户区上方那里是给客户的银行资料，混入内部折算金额口径不对
页面顶部 / 标题旁金额还没算出来时显示空值，反而干扰

合计条本来就是"这单多少钱"的唯一展示位，把折算挂在旁边最自然；不新增列、不破坏刚修好的三列对齐，也不用改数据模型。

3 · 边界（这次特别守住的几条）

客户拿到的 PI / PDF：只有 USD 368.00 和打印件 TOTAL，不含人民币、不含汇率。折算只存在于 OA 内部表单界面（之前刘总已明确「人民币参考不显示在 PI」）。
情况显示
正常外币（USD / EUR …）「折合人民币 ¥2,461.92 · 内部参考」，按系统汇率实时算
币种就是 CNY标签改「人民币金额」，不写"折合"（没有折算发生）
该币种未配置汇率显示「汇率未配置」，不拿原金额冒充人民币
改明细 / 切币种 / 汇率更新两个金额一起自动变，无需手点重算
列表页原本就有「人民币金额（内部参考）」列，本次未改
没有做的事：没有加"奖金/提成"计算（刘总说的是"折算成人民币大概是多少钱"，再往下推断提成比例属于另一件事）；没有把人民币写进打印数据；没有新建表、字段或接口；汇率仍取 currencyStore 系统真源，不写死数值。
