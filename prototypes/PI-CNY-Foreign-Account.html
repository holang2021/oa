HOLANG All in One OA · 收款账户口径
2026-11-09 · 人民币外币账户 + 空回款路径删除

PI 选人民币：走「人民币外币账户」，空回款路径整行删掉

刘总原话：「在做 PI 的时候，选择人民币账户应该是选『人民币外币账户』，而不是普通国内账户，汇款路径之类的都是外币账户啊」「再有回款路径若是空白，请删除掉」

此前系统里人民币只有一套「国内中文账户」，开 PI（外销单据）选 CNY 时会带出「开户行 / 行号 / 收款人」这类内销口径的中文信息，客户拿到手看不懂、也对不上外销的 SWIFT 路径。现在把人民币拆成两套账户，各管各的场景；另外只要回款路径没填，那一行就彻底不显示，不出现「—」、不出现空标签、不出现占位提示。

一句话：PI 是给国外客户看的单据，就算收人民币，也得按「外币账户」那套英文资料走（Bank details / SWIFT / PAYMENT ROUTE）；普通国内中文账户只留给内销回款，不会串到 PI 里。

1 · 改前 / 改后

改前

PI 币种选 CNY

  • 只找到一套人民币账户：人民币账户 · 内销回款
  • 打印件银行块变成中文：收款账户信息：
  • 字段是「开户行 / 银行行号 / 收款人 / 账号」——国内转账口径
  • 没有 SWIFT、没有 Benenficiary Bank、没有 PAYMENT ROUTE
  • 回款路径没填时，仍印一行 PAYMENT ROUTE: —

结果：国外客户看不懂，销售只能回 Excel 手工改，等于白做。

改后

PI 币种选 CNY

  • 优先命中 人民币外币账户 · 出口收汇
  • 打印件银行块一律英文：Bank details:
  • 字段为 Beneficiary Bank / Bank Address / Swift Code / Beneficiary / Account No.
  • 与 USD、EUR 单据完全同一套口径
  • 回款路径空白 → 整行删除，不留任何痕迹

普通国内中文账户仍在，供内销回款和中文复制使用，不再误入 PI。

2 · 现在系统里的四套账户（各管各的）

账户性质币种用在哪资料口径
外币账户 · 出口收汇USD外销 PI / CI，收美元全英文，Bank details + SWIFT + PAYMENT ROUTE
外币账户 · 出口收汇EUR外销 PI / CI，收欧元全英文，同上
人民币外币账户 · 出口收汇CNY外销 PI 选人民币时自动带出全英文，与美元 / 欧元账户同一套口径
人民币账户 · 内销回款CNY国内回款、中文复制给国内客户全中文，开户行 / 行号 / 收款人 / 账号

资金账户页「账户性质」下拉已增加「人民币外币账户 · 出口收汇（英文）」，管理员可自行新增、删除、设为默认；删除账户不会被系统偷偷补回来。

6 · 还请刘总拍板的两件小事

① CI / PL 要不要同步？

本次「人民币外币账户」逻辑同时作用于 PI 与 CI（PL 无银行块）。CI / PL 的产品编号列、币种子表头、金额符号目前还是老样子，要不要一并按真实单据补齐？

② 银行块第 6 行的去留

当前规则是「填了就印、空了就整行删」。如果以后所有外销单据都不需要 PAYMENT ROUTE，可以直接从模板里拿掉这一行，连填写框一起省掉。
