# HOLANG All In One 企业管理系统 — 架构规划

> 规划日期：2026-06-26 | 基于伙伴云蓝本 + 制造型工厂业务场景

---

## 一、三大领域统筹

| 域 | 全称 | 覆盖范围 | 核心模块 |
|----|------|---------|---------|
| **CRM** | Customer Relationship Management | 客户全生命周期 | 线索→客户→商机→报价→订单→回款→售后 |
| **SRM** | Supplier Relationship Management | 供应商全生命周期 | 供应商→询价→采购→到货→验收→应付 |
| **ERP** | Enterprise Resource Planning | 企业资源计划 | 产品→BOM→生产→仓储→财务→报表 |

三者关系：

```
          ┌──────────────────────────────┐
          │          ERP（内核）          │
          │  产品 · BOM · 生产 · 仓储 · 财务  │
          └──────┬──────────────┬────────┘
                 │              │
        ┌────────▼───┐    ┌────▼──────────┐
        │   CRM      │    │     SRM       │
        │ 客户 · 销售  │    │ 供应商 · 采购   │
        └────────────┘    └───────────────┘
```

**ERP 是骨架**（共享主数据：产品、BOM、库存），**CRM 和 SRM 是双手**（一边卖出去，一边买进来），**财务是血液**（贯穿全程）。

## 三、千人千面 — 角色权限体系

### 设计原则

> 每个人登录后只看到自己该看到的，**菜单不同、数据不同、操作不同**。

### 角色定义（8 类）

| 角色 | 可见域 | 数据范围 | 典型操作 |
|------|--------|---------|---------|
| **销售员** | CRM·内销 或 CRM·外销 | 本人客户/线索/商机 | 录入跟进、创建报价、提交审批 |
| **销售经理** | CRM·内销/外销 | 本团队全部数据 | 分配线索、审批报价、查看团队报表 |
| **销售总监** | CRM·全部 + 总览 | 全公司销售数据 | 数据分析、策略调整 |
| **采购员** | SRM + 仓储（只读） | 本人采购单 | 创建采购订单、跟进到货 |
| **仓管员** | 仓储管理 | 所管仓库 | 出入库操作、盘点 |
| **生产主管** | ERP·生产 + BOM | 本车间 | 排程、派工、质检 |
| **技术工程师** | 技术研发 + 产品 + BOM | 全部技术文件 | 新建/修改 BOM、ECN |
| **财务** | 财务管理 + 部分 CRM/SRM | 全部财务数据 | 开票、收款、付款、对账 |
| **总经理** | 全部 + 系统管理 | 全部 | 查看所有数据、系统配置 |

### 实现方式

```
登录 → 企微 OAuth 获取 UserID
        │
        ▼
  查询角色表 → 确定角色（可多角色）
        │
        ▼
  生成动态菜单树（仅显示有权限的模块）
        │
        ▼
  所有 API 请求自动注入角色 → 后端校验数据权限
```

**前端**：菜单根据角色动态渲染，无权限的模块直接不显示在侧边栏。
**后端**：每个 API 请求校验 `userId + role + dataScope`，确保跨权限访问被拦截。

## 五、技术约束

| 项 | 决定 |
|----|------|
| 登录方式 | 仅企微 OAuth（无密码登录） |
| 数据存储 | Phase 1-2 本地 JSON/飞书 Bitable，Phase 3+ 自建数据库 |
| 部署方式 | 云端服务器（腾讯云轻量） |
| 访问入口 | 企微工作台 H5 + PC 浏览器 |
| 审批引擎 | 自建动态组件（已完成），不依赖三方 |
| 通讯录 | 企微 API 同步，不独立维护 |
