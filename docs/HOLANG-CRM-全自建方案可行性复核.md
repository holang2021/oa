### 环节 1：从伙伴云导出全部数据 → 拿到蓝本

| 检查项 | 状态 | 说明 |
|--------|------|------|
| 列出工作区下所有表格 | ✅ | `POST /openapi/v1/table/list`，返回 table_id + 名称 |
| 获取每张表的字段结构 | ✅ | 可获取字段名、类型、是否必填、关联关系 |

## 二、3 个关键前提（需要你确认）

### 前提 1：数据存储方案

两个选择：

| 方案 | 优点 | 缺点 |
|------|------|------|
| **A. 飞书 Bitable** | 已有配置，免运维，可视化编辑，朗工可直接读写 | 免费版有行数限制，大数据量需付费 |
| **B. 自建数据库（SQLite/MySQL）** | 完全自主，无行数限制，性能好 | 需要服务器，需运维 |

**建议**：初期用飞书 Bitable（免费够用），数据量大了再迁 MySQL。

### 前提 2：云服务器

H5 页面需要托管。你现在有可用的服务器吗？
- 有 → 直接部署
- 没有 → 腾讯云轻量应用服务器（¥50~100/月），WorkBuddy 可直接部署

### 前提 3：伙伴云 API Key

没有 Key 就没法导出数据。最快的方式：登录伙伴云 → 设置 → 开放平台 → 创建 API Key。
