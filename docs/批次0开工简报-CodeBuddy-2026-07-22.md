## 二、代码规则门禁（tech-lead 强制 · 不合规不得合并）

技术栈：**Express4 + 严格分层(Controller/Service/Repository) + Prisma/zod/TS**，不换 Java、不盲追 NestJS。

1. 分层：Controller 只接参/返响应；Service 只写业务；Repository 只碰 Prisma。禁 service 碰 req-res。
2. 数据访问：禁非 Repository 写 Prisma；所有写经 Repository + transaction。
3. 类型：`strict:true`；**禁 `as any`**；入参 zod 校验；出参统一 DTO。
4. 错误响应：统一 `{code, message, traceId}`；禁裸 throw；业务错误码枚举化。
5. 日志：pino 结构化；写/导出/公海操作落 audit_log。
6. 隔离：涉客户/商机/公海接口必须 `salesType` 透传 + 服务端域强制（复用 Phase1 B1）。
7. **AI 边界(H-3)**：本批次无 AI 写路径；若接数字员工只读展示，仅出现在只读路径，禁止自动落库。
8. 测试：Service 单测覆盖率 ≥ 60%；关键路径（RBAC 拦截 / 防下载 403 / 公海隔离）集成测试必过。
9. review：本专家 review 产出，卡住不合规代码。
