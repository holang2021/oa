## 6. 残留风险与刘总本地需做事项

**残留风险：** 本环境无存活 PAT；但历史提交中若曾存在旧 `github_token.txt` 内容（占位模板，非真密钥）已无意义。真正的 GitHub 推送能力此前依赖刘总本机配置。

**刘总在本地 machine 必须完成的事项：**
1. **轮换 GitHub PAT**：在 GitHub 后台吊销 / 重新生成 Personal Access Token，确保旧令牌失效（即使旧令牌只是占位，也建议建立轮换习惯）。
2. **本机建 `.env` 并填新 PAT**：将仓库根 `.env.example` 复制为 `.env`，填入新的 `GITHUB_TOKEN=ghp_xxx`，保存。该文件被 `.gitignore` 覆盖，不会入库。
3. **OA 凭据**：若 OA 后台实际登录凭据**非默认** `admin / admin123`，必须在 `.env` 中填入 `OA_USERNAME=` / `OA_PASSWORD=` 真实值；若沿用默认则留空即可（脚本自动回退）。
4. **推送**：刘总用离线 bundle 方式完成 GitHub 优先备份；如需在本地跑 `push_repo.bat`，令牌将仅通过临时凭据文件注入 `git`，不会进入命令行参数或控制台。
