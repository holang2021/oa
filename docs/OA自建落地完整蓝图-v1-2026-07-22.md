## 三、模块边界与接口契约（9 模块 + 4 迭代）

> 约定：所有跨模块调用经 Service 层 + 统一错误响应（`{code,message,traceId}`）；所有写操作落 audit_log；`salesType` 透传所有涉客户/商机/公海接口（服务端强制隔离）。

### M1 工作台（首页=统一待办中心 · P3 拍板）
- 边界：聚合「审批待办 / 公海认领 / 回访提醒 / 回款催办 / 离职移交(接H-4) / 客户等级降级(接P2)」；模块侧边导航保留不砍。
- 接口：`GET /api/todo/aggregate`（按 userId + RBAC）、`GET /api/me/view`（我的待办/客户健康/获客漏斗 · 共识#5）。
- 物理件：统一待办聚合服务（定时任务扫 approval-engine + 公海 + 回访 + 回款 + 移交 + 降级事件）。

### M2 产品管理
- 边界：产品目录（设备：制氮/制氧/制氢机+配套）+ 销售信息（成本/含税价/税率/毛利公式）+ 图片 + 审核。
- 接口：`GET/POST /api/products`、`POST /api/products/:id/pricing`。
- 闸门：B（填充 products 目录）→ C（pricing 子表）。

### M3 市场管理
- 边界：线索公海（分配/回流/总监审批）+ 市场活动 + 名片 OCR（C 项 · 批次2）+ 区域归因（D 项）。
- 接口：`POST /api/leads`（含 `region/source/industry`）、`POST /api/leads/claim`、`GET /api/marketing/campaigns?region=`、`POST /api/ocr/business-card`（预填→人确认）。
- 区域归因：`leads.region` 直接复用 + `marketing_campaigns.region` 字段。

### M4 客户管理（聚合根 H-4 · 查重 · 等级A/B/C）
- 边界：客户信息 + 行业 + **客户等级A/B/C(按需求紧迫度)** + 查重(信用代码/DUNS) + 公司信息变更 + 员工背调(DeepSeek) + 族谱 + 联系人 + 开票 + 异动 + 客户公海。
- 接口：`POST /api/customers`（4选择题提示分级 + 自动生成下次跟进日期）、`GET /api/customers/:id/dedupe`（DeepSeek）、`POST /api/customers/:id/background-check`。
- **聚合根 H-4**：客户下所有从属实体（联系人/商机/报价/合同/订单/回款/开票/售后/跟进/异动）随客户整体移动（移交/退公海/分配），不单独分离。

### M5 销售管理（P4 主闭环）
- 边界：线索→商机→报价→合同→订单→发货→回款；**外销分支(参考询盘云)：PI/PL/合同统一模板**；**内销分支(参考励销云·销售易)：商务合同结构化**。
- 接口：`POST /api/opportunities`、`POST /api/quotes`、`POST /api/contracts`、`POST /api/orders`、`POST /api/deliveries`、`POST /api/pi`（外销 PI 生成）。
- **MVP 主闭环（P4 拍板）**：客户(A/B/C)→商机→报价/PI→合同→订单→回款，内外销共用骨架。

### M6 售后服务
- 边界：客户回访 + 售后工单（含现场媒资/满意度/审批/机器维度）+ 知识沉淀；二期关联售后报价/合同/质保计费。
- 接口：`POST /api/service-requests`、`POST /api/service-requests/:id/visit`（回访）、`GET /api/service-requests/:id/context`（自动带出客户/合同/机器 · 共识#7）。
- 闸门：C（新建 service_requests/knowledge/equipment）。

### M7 财务管理
- 边界：已回款/已开票(A) + 回款计划/回款申请(C) + 开票申请(数电票 B/C) + 销售对账/付款单/资金账户(C)。
- 接口：`GET /api/payments`、`POST /api/receipt-plan`、`POST /api/invoice-apply`。

### M8 数据分析（D 项区域归因）
- 边界：9 类统计 + 地图 + **区域维度**（外销标准分析口径）。
- 接口：`GET /api/analytics/:type?region=&salesType=`、`GET /api/analytics/region-dist`（按国家/大区切片）。
- **拆 GEO**：GEO（生成式引擎优化）属官网营销层，不进 OA 系统（D 拍板）。

### M9 生产管理（接迭代#4）
- 边界：工程技术确认 / BOM / 工单；与制造系统衔接。
- 接口：`POST /api/bom`、`POST /api/work-orders`。

### 迭代#1 一体化沟通（P1 拍板）
- 边界：企微+邮件+WhatsApp+微信 **系统级留痕**（原始对话/线索自动落库，系统写非AI写，不碰H-3）；**AI 对话摘要后置 H-3 阶段1**。
- 接口：`POST /api/comms/ingest`（邮件/WhatsApp/微信 webhook → 落库 + 线索识别）。

### 迭代#2 导入导出（含伙伴云迁移 · 第五节）
- 边界：伙伴云 API 拉取 + 规则清洗 + 按 huobanId upsert；导出 RBAC 仅管理员/财务对账（H-2）。
- 接口：`POST /api/migration/huoban/sync`、`GET /api/export`（RBAC 受控）。

### 迭代#3 AI 层（H-3 约束）
- 边界：阶段0 仅读取展示/提示；阶段1 放开填写；阶段2 不授决策权。
- 接口：`GET /api/ai/customer-health`（只读预警）、`GET /api/ai/template-preview`（只读预检）、`POST /api/reports/submit`（日报周报系统内提交 · 系统功能非AI）。

### 迭代#4 供应链/制造
- 边界：与 M9 衔接，蓝图规划、批次3 落地。

## 六、外销/内销对标 + 统一文件模板引擎

## 八、公海设计 + 内销/外销绝对隔离 + 防下载（H-2）

- **线索公海（独立）**：`leads` + pool 状态位 + 分配/回流/总监审批。
- **客户·商机公海（共用机制）**：`customers`(无主账号) + `opportunities`(无主商机)，共享 claim/return 规则，视图按类型切换。

## 十二、代码规则（tech-lead 强制 · review 门禁）

技术栈：Express4 + 严格分层(Controller/Service/Repository) + Prisma/zod/TS，**不换 Java、不盲追 NestJS**。

1. **分层**：Controller 只接参/返响应；Service 只写业务逻辑；Repository 只碰 Prisma。禁 service 碰 req-res。
2. **数据访问**：禁非 Repository 层写 Prisma；所有写经 Repository + transaction。
3. **类型**：`strict:true`；禁 `as any`；入参 zod 校验；出参统一 DTO。
4. **错误响应**：统一 `{code, message, traceId}`；禁裸 throw；业务错误码枚举化。
5. **日志**：pino 结构化日志；所有写/导出/公海操作落 audit_log。
6. **隔离**：涉客户/商机/公海接口必须 `salesType` 透传 + 服务端域强制（复用 Phase1 B1）。
7. **AI 边界(H-3)**：数字员工/AI 调用仅出现在只读展示/提示路径；写/审批路径显式"人确认"节点，禁止 AI 自动落库生效。
8. **测试**：Service 单测覆盖率 ≥ 60%；关键路径（公海隔离/审批触发/模板强校验）集成测试必过。
9. **review**：本专家 review 执行层(CodeBuddy)产出，卡住不合规代码；不合规不得合并。
