# 企业微信联系人导入 OA 方案 V1

> 评估结论：**技术上可行，但受限于企微权限与合规要求，需刘总拍板是否接入、以及接入范围。**

---

## 一、需求澄清

### 1.1 微信 vs 企业微信：必须分清楚

| 平台 | 能否让 OA 自动导入联系人 | 说明 |
|------|------------------------|------|
| **个人微信** | ❌ 不能 | 微信未向任何第三方开放「读取个人通讯录/好友列表」的官方 API。任何声称能导个人微信联系人的方案都是非官方逆向，有封号与法律风险。 |
| **企业微信** | ✅ 能（有限度） | 企业微信提供「客户联系」相关 API，可拉取**已添加为外部联系人的客户**信息，包括：昵称、备注名、头像、性别、企业简称、手机号（需单独授权）、标签等。 |

**结论**：OA 只能从**企业微信**导入「外部联系人」（即员工在企微里添加的客户联系人），不能从个人微信导入。

---

## 二、企微能拿到什么字段

企业微信「获取客户详情」接口（`/externalcontact/get`）可返回：

| 字段 | 是否可获取 | 备注 |
|------|-----------|------|
| 昵称（external_userid） | ✅ | 唯一标识 |
| 备注名 | ✅ | 员工设置的备注 |
| 头像 | ✅ | URL |
| 性别 | ✅ | 男/女/未知 |
| 企业简称 | ✅ | 如有 |
| 手机号 | ⚠️ 需特殊权限 | 属于敏感字段，需开通「客户联系」相关接口权限，并可能涉及用户授权 |
| 标签 | ✅ | 可映射为 OA 联系人标签/类型 |
| 员工跟进人 | ✅ | 对应 OA 创建者/负责人 |

---

## 三、与 OA 联系人表的映射

| 企微字段 | OA Contact 字段 | 处理说明 |
|---------|----------------|---------|
| 备注名/昵称 | `name` | 优先用备注名，无备注用昵称 |
| 性别 | `gender` | MALE/FEMALE/UNKNOWN |
| 企业简称 | `dept` / `position` | 可先写入 `dept` |
| 手机号 | `phone` | 需授权后写入 |
| 头像 URL | （暂无字段） | 可后续扩展 |
| 跟进员工 | `createdById` | 同步时写入对应员工 OA 用户 ID |
| 外部联系人 ID | `huobanId` 或新字段 | 用于去重与后续同步 |
| 标签 | `contactType` / 扩展字段 | 可映射 |

**关键约束**：导入的联系人必须归属到某个 `Customer` 下。若企微外部联系人未与 OA 客户关联，需先让客户选择/新建客户，再导入联系人。

## 四、实现路径（分阶段）

### 阶段 1：最小可用（推荐先落地）
1. 后端新增企微外部联系人同步任务：
   - 调用企微 API `/externalcontact/list` 获取外部联系人 ID 列表；
   - 调用 `/externalcontact/get` 获取详情；
   - 按「跟进员工」映射到 OA 用户作为 `createdById`；
   - 在 OA 客户详情页提供「从企微导入联系人」按钮，员工选择一个外部联系人后，写入该客户的 Contact 表。
2. 前端：客户详情页联系人列表增加「从企微导入」入口。
3. 权限：仅允许导入「我是跟进人」的外部联系人，避免跨员工数据越权。

### 阶段 2：自动关联与业务跟进
1. 企微外部联系人 ↔ OA 客户主数据建立映射（通过企业简称/手机号匹配，或人工绑定）。
2. 同步后可在 OA 时间轴/跟进记录里显示「来自企微」的标识。
3. 可选：企微回调监听新增客户事件，自动同步到 OA（需配置接收事件服务器）。

## 五、需要刘总准备/授权的事项

| # | 事项 | 说明 |
|---|------|------|
| 1 | **企微管理员授权** | 需在企微管理后台给自建应用（1000081）开通「客户联系」权限，包括：外部联系人管理、获取客户详情等。 |
| 2 | **敏感字段授权** | 手机号属于敏感字段，需在企微后台申请并可能需要员工/客户授权。 |
| 3 | **接入范围** | 是全员启用，还是先让外销/售后等特定部门使用？ |
| 4 | **数据归属规则** | 企微联系人导入后，创建者自动为「企微里的跟进员工」，是否允许主管调整？ |

## 六、风险与限制

| 风险 | 等级 | 说明 |
|------|------|------|
| **个人微信无法导入** | P0 | 若业务场景是个人微信好友，此方案不可行。 |
| **手机号等敏感字段受限** | P1 | 需额外权限，可能无法默认拿到。 |
| **外部联系人必须已存在** | P1 | 只能导入员工已添加的企微客户，不能凭空获取。 |
| **频率限制** | P2 | 企微 API 有调用频率限制，大批量同步需分批+缓存。 |
| **合规与隐私** | P1 | 需确保员工/客户知情同意，避免违规收集个人信息。 |

---

## 七、建议决策

**如果外贸团队主要用「企业微信」加海外客户**：建议按阶段 1 接入，开发量可控（约 1-2 天），能明显减少手动录入。

**如果主要用「个人微信/WhatsApp」加客户**：企微方案不适用；WhatsApp 联系人导入需走 Meta 官方 Business API，与个人号好友列表同样不可导入。
