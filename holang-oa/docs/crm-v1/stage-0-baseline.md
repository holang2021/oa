## 本阶段修正

1. 测试数据库不再依赖过期的固定文件名，改为读取当前配置库并复制到隔离副本。
2. 测试副本使用固定的客户等级配置，避免运行库人工配置造成不稳定断言。
3. 公海测试使用测试标记搜索，避免真实数据分页遮住测试样本。
4. 角色矩阵断言与当前 15 个权威角色保持一致。
5. 跟进日期断言以请求前时间为基准，消除毫秒级边界误差。

## 已知风险

1. SQLite 仍是当前运行数据库，不满足全员上线后的并发与运维目标；阶段 1 必须先在独立测试库完成 PostgreSQL 迁移和回滚演练。
2. 当前前端主 JavaScript 包约 1.06 MB，构建有大包警告；不阻塞阶段 0，但上线验收前需要评估首屏性能。
3. 商机、报价记录均为 0，阶段 1 的迁移核对需要建立可回滚的测试样本。
4. 本地测试账号和开发配置不得直接作为生产凭据；上线前必须禁用或轮换默认测试凭据。
5. DeepSeek 查询结果不是权威工商或 DUNS 数据，本轮只能作为未核验联想信息。
