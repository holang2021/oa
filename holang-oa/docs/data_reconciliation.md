## 七、结论

**数据核对通过。** 内销/外销分类规则明确，映射正确，无串台。

核心要点:
1. 客户层面 `salesType` = INTERNAL/EXTERNAL，描述客户注册地（国内/海外）
2. 订单层面 `businessLine` = INDUSTRIAL/RETAIL，描述交易性质（内销/外贸）
3. 两者允许不一致（如国内贸易公司做出口订单），这不是 bug
4. 所有 394 个客户和 274/283 笔订单的分类标记与伙伴云原始数据一致
